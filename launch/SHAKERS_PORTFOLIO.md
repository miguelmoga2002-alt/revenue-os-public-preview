# Portfolio / Shakers — Revenue OS

**SaaS B2B y producto comercial end-to-end.** He diseñado y desarrollado Revenue OS, un sistema de gestión y ejecución comercial orientado a reducir operaciones manuales y dar trazabilidad a cada oportunidad. El núcleo implementado incluye CRM/Kanban, Deal Workspace con Account 360, tareas priorizadas, flujos para comerciales y responsables, importación CSV/XLSX y auditoría. Abordo el desarrollo con hipótesis de negocio, criterios de aceptación y medición del retorno, evitando presentar como resultados los ahorros todavía no validados.

**Arquitectura full-stack y seguridad multiempresa.** El backend utiliza Python 3.12, FastAPI, Uvicorn, Pydantic, SQLAlchemy, Alembic y psycopg sobre PostgreSQL 16, además de SQLite en pruebas. El frontend está desarrollado con HTML5, CSS3 y JavaScript nativo. La infraestructura emplea Docker/Docker Compose y GitHub Actions, con autenticación, MFA TOTP, RLS por empresa, permisos por registro, sesiones revocables, idempotencia, auditoría y validaciones automatizadas con pytest, Playwright, axe-core, Bandit y pip-audit.

**IA aplicada a procesos, con evaluación y supervisión humana.** Revenue OS está evolucionando hacia un AI Sales Operating System que incorpore captura de señales con fuente verificable, recomendaciones de próxima acción y borradores comerciales sujetos a aprobación. El producto hoy prioriza mediante reglas deterministas; la integración con LLMs cloud/local, la transcripción y las automatizaciones multicanal siguen en diseño y no se presentan como capacidades desplegadas. Mi trabajo conecta ingeniería, Revenue Operations y gestión del riesgo para construir software comercial demostrable y preparado para un futuro piloto responsable.
